# Planejamento Operacional
## Inicio: Cliente envia programação com os requisitos
### Focal Preenche com as informações abaixo:
- Focal Responsável = Nome do focal responsável pelo preenchimento
- Data/Hora do Lançamento = Hora da solicitação
- Data/Hora Liberação = Data/Hora que foi verificado se a operação está liberada
- Cliente = Nome do Cliente que será atendido
- OS/Referência = Número da Ordem de Serviço ou documento similar
- Tipo = Tipo de operação (Importação, Exportação, Cabotagem Importação e Cabotagem Exportação)
- DI/Booking = Identificador de Booking (rastreamento) -> gerado pelo cliente
- Armador = Empresa dona do conteiner
- Tamanho do Conteiner
- Status Atendimento = Liberado, Cancelado, Pendencia Documento, Frete Morto
- Conteiner  
- Conteiner Exportação 
- Tara 
- Lacre 
- Genset 
- Excesso = Informar caso a carga necessite de adequaçao por excesso nas medidas
- Valor da Carga 
- Peso  
- IMO = Se Inflamável, contaminante...
- Coleta = Local de coleta do conteiner
- Detention/Demurrage = Data limite para devolução do conteiner vazio
- Local Atendimento = Cidade/Região do Atendimento
- Data e Hora = Data e Hora do Atendimento
- Devolução Vazio = Data da devolução do conteiner vazio (Controle interno)
- Agendamento Coleta = Data de coleta do conteiner
- Agendamento de Entrega = Entrega no porto pra exportação
